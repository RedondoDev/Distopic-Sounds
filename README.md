# 🎧 Distopic Sounds

## A Modern Recording Studio Website

Corporate website for **Distopic Sounds**, a recording studio focused on music creation, production, mixing, and mastering. This project delivers a strong and coherent visual identity while clearly presenting the studio’s services, collaborating artists, physical location, and an intuitive appointment booking flow.

The website is conceived as a clean, modern landing page with rich media content and smooth interactions, prioritizing both aesthetics and usability across all devices.
